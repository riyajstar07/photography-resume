# riya.clicks ✦ Riya Jaiswal — Photography & Videography Portfolio

A hand-drawn, doodle-style portfolio for photography, videography, event coverage, editing, content creation and social media handling.

- ✏️ Doodle icons, washi tape, polaroids, sticky notes and a notebook-paper "about me"
- 🌙 Paper ↔ chalkboard (light / dark) toggle
- 📸 Camera-flash + lightbox when you click a photo
- 🏍️ A doodle bike that rides across the page as you scroll
- ✉️ Contact form that opens an email to riyajstar07@gmail.com
- 📱 Fully responsive, plain HTML/CSS/JS — no build step

## Adding your photos

Drop images into the `images/` folder with these exact names — they show up automatically. Until then, each polaroid shows a coloured doodle placeholder.

| File | Where it appears |
| --- | --- |
| `images/hero-1.jpg` | Hero polaroid — "me + my camera" |
| `images/hero-2.jpg` | Hero polaroid — "event nights" |
| `images/hero-3.jpg` | Hero polaroid — "ride days" |
| `images/work-1.jpg` | Work — golden hour portraits (photo) |
| `images/work-2.jpg` | Work — café menu shoot (café) |
| `images/work-3.jpg` | Work — event night highlights (event) |
| `images/work-4.jpg` | Work — reels & BTS (video) |
| `images/work-5.jpg` | Work — everyday lifestyle (photo) |
| `images/work-6.jpg` | Work — celebrations (event) |
| `images/work-7.jpg` | Work — food & flat-lays (café) |
| `images/work-8.jpg` | Work — ride diaries (video) |

Tip: portrait-ish (4:5) photos look best. Keep each under ~500 KB so the site stays fast.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
